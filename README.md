# Mais Tower Defense

Pixel-Tower-Defense-Spiel aus der Republik Maiskolbistan – vom Präsidenten. Läuft direkt im Browser, ohne Anmeldung.

**Spielen:** https://nikesieg4.github.io/Mais-Tower-Defense/

## Dateien

| Datei | Inhalt |
| --- | --- |
| `index.html` | Das ganze Spiel (eine Datei, Canvas 384 × 272) |
| `.nojekyll` | GitHub Pages liefert die Datei unverändert aus |

## Speicherstände

Der Fortschritt wird im Browser gespeichert (nach jeder geschafften Welle). Unter **Einstellungen (Zahnrad) → Spielstand**:

- **Herunterladen** – Spielstand als `.json`-Datei sichern (z. B. für ein anderes Gerät)
- **Hochladen** – gesicherten Spielstand wieder einspielen (wird vorher geprüft, mit Rückfrage)
- **Lauf neu starten** – neuer Lauf, Kristalle und Fähigkeiten bleiben
- **Alles zurücksetzen** – kompletter Spielstand gelöscht

## Veröffentlichen

GitHub Pages: *Settings → Pages → Build and deployment → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)`*. Jede Änderung an `main` ist danach nach ca. 1 Minute online.

Weitere Infos zu allen Maiskolbistan-Seiten: Repo `nikesieg4/Maiskolbistan-Info` (`seiten/spiele/spiele/pixel-tower-defense/`).
